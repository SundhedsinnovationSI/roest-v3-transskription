Røst mødetransskription

Transskriberer danske mødeoptagelser og skelner talerne fra hinanden. Alt foregår i din browser, og lyden forlader ikke din computer.

1Vælg lydfil

Fx m4a fra iPhone, mp3 eller wav.

2Hvor mange personer taler i optagelsen?

Det rigtige antal giver den mest præcise taleradskillelse.

3Om mødet (valgfrit, bruges i referatet)

4Transskriber

Vælg en lydfil og antal personer.

Hold fanen åben, mens der arbejdes. Du kan godt bruge andre programmer imens.

5Resultat

Maskingenereret med Røst v3. Ikke rettet af et menneske.

Åbn Claude

Referat: Klik på «Kopiér til Claude (referat)», åbn Claude, og indsæt med Ctrl+V. Teksten indeholder både vejledning, skabelon og transskription.

Talegenkendelse: Røst v3 fra CoRal-projektet (licens: tilpasset OpenRAIL-M; maskingenereret indhold skal mærkes som maskingenereret). Taleradskillelse: pyannote segmentation 3.0 (MIT) og CAM++ fra 3D-Speaker via sherpa-onnx (Apache 2.0). Beregning: ONNX Runtime Web (MIT).
