# Røst Referat (Claude-side)

Kildefilen til Claude-siden «Røst Referat»: https://claude.ai/artifact/8e3cXgRnJkhBSjsKHSRmdF

Siden modtager transskriptionen fra websiden i `docs/` (knappen «Referat» kopierer den, brugeren trykker Ctrl+V),
lader Claude skrive referatet via brugerens egen Claude-konto og leverer det som Word-fil efter referatskabelonen.
Den bruger Claude-sidernes funktioner `sample` (spørg Claude) og `downloads` (hent fil).

Ændringer udgives fra Claude Code med Artifact-værktøjet til samme adresse.
